# Drive Mode Haval F7/F7X 

Приложение для управления режимами движения (Normal, Sport, Eco, Snow, Sand, Off-road) и вывода статистики поездки на приборную панель автомобиля.

## 🚀 Возможности
* **Переключение режимов АКПП:** Удержание кнопки `Mute` на руле (1 секунда) переключает выбранные в приложении режимы.
* **Статистика поездки на приборке:** Короткое нажатие кнопки `Back` выводит красивую карточку с данными (пробег, время в пути, средний расход, израсходовано литров) прямо поверх штатной приборки.
* **Автономность:** Приложение работает в фоне как Foreground Service и переживает перезагрузки (BootReceiver).
* **Совместимость:** Работает на штатном Binder-сервисе ГУ (`GwmAdapterService`), не требует Root-прав.

## ⚠️ Важные ограничения
* Вывод статистики по кнопке `Back` работает корректно только в режиме **БК (Бортовой Компьютер)**.
* Пробег и расход могут отображаться прочерками (`—`), если автомобиль стоит на месте. Для получения данных от CAN-шины требуется начать движение.

## 🛠 Технические особенности
* Используется класс `Presentation` для вывода интерфейса на второй дисплей (приборку). Это обходит системные запреты QNX/Android на обычные оверлеи (`WindowManager`).
* Обработка кнопок руля реализована через перехват Binder-вызовов (`HardKeyManager`).
* Отрисовка карточки статистики происходит на чистом `Canvas` без использования тяжелых XML-верстка.

## 📦 Сборка
Проект собирается в Android Studio / Code on the Go (Gradle 8+).
Минимальная версия Android: 9.0 (API 28).
