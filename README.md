# Drive Mode (Haval / GWM)

Неофициальное приложение для управления режимами АКПП (NORMAL, SPORT, ECO, SNOW, SAND, OFF-ROAD) с кнопок на руле автомобилей Haval / GWM с головным устройством на Android.

Приложение работает **без root**, **без ADB** и **не требует специальных разрешений**. Взаимодействие с автомобилем происходит через штатный Binder-сервис `com.gwm.android.adapter.server.GwmAdapterService`.

## Возможности

- **Управление с руля:** Удержание кнопки `Mute` (~1.5 сек) переключает режимы вождения.
- **Гибкая настройка:** В приложении можно отметить галочками любые из доступных режимов (NORMAL, SPORT, ECO, SNOW, SAND, OFF-ROAD). Кнопка на руле будет переключать их по кругу.
- **Работа в фоне:** Служба работает как Foreground Service и автоматически запускается после перезагрузки ГУ.
- **Инженерное меню:** В лаунчере появляется отдельный ярлык для быстрого доступа к скрытому инженерному меню ГУ.

## Требования

- Головное устройство Haval / GWM на базе Android.
- Установленный штатный системный сервис `com.gwm.android.adapter.server` (присутствует на всех ГУ GWM/Haval).

## Установка

1. Установите APK на головное устройство.
2. Откройте приложение. Служба запустится автоматически (если нет — нажмите «Перезапустить службу»).
3. Выберите нужные режимы галочками и нажмите «Сохранить».

*Никаких дополнительных разрешений или ADB-команд не требуется.*

## Использование

1. Запустите двигатель.
2. **Нажмите и удерживайте кнопку `Mute` (~1.5 секунды)** на руле.
3. Режим переключится на следующий из выбранных вами.
4. Повторное удержание переключит режим дальше по кругу.

*Также поддерживается удержание кнопки `Back` (2006), но она работает только в режиме бортового компьютера (БК).*

## Как это работает

В основе приложения лежит использование штатного Binder-сервиса `GwmAdapterService`:

1.  **Получение событий:** Приложение подписывается на системное событие `sys.other.keyevent_notify` через Binder (используя listener `IDataChangedListener`). Это позволяет получать нажатия кнопок руля в реальном времени без использования `READ_LOGS`.
2.  **Переключение режимов:** При удержании кнопки отправляется команда `setData` в свойство `car.drive_setting.drive_mode`. 
3.  **Обход проверки прав:** Так как для записи требуется системное разрешение `SET_DATA`, приложение использует особенность проверки прав в сервисе: в запросе подставляется `packageName` штатного приложения (`com.gwm.app.vehicle.center`), у которого это право есть.
